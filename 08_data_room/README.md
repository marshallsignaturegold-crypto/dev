Master HTML institutional documents, thesis publications, and data room packaging outputs.

This directory is the authoritative location for the programme's primary institutional documents. All documents here are versioned and represent the current canonical state of programme materials.

## Intended artifacts

- `SSS_AIA_SMCC_Master_Institutional_Document.html` — v12.0 Master Institutional Document (March 18, 2026)

## Required ID conventions

- Document IDs: `DOC-DR-NNN`
- Market data must carry "scenario/projected" disclaimers

## Market Data Note

Gold and silver prices appearing in these documents (e.g., Gold ~$5,008/oz, Silver ~$81.81/oz) are **scenario projections for modeling purposes** as of the document date. These do not represent current market prices.
