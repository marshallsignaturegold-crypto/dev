# 08_data_room — Institutional Master Documents

## Purpose

This directory is the data room for the SignatureSovereign SafeTrade Program, containing the master institutional HTML documents intended for institutional distribution to government agencies, financial institutions, and qualified investors.

## Contents

| File | Description | Version |
|------|-------------|---------|
| `SSS_AIA_SMCC_Master_Institutional_Document.html` | AI-SMCC Master Institutional Document — full programme prospectus and architecture | v12.0 |
| `SafeTrade_Program_Masters_Thesis.html` | SafeTrade Program academic thesis submission | v1.0 |

## Classification

> **CONFIDENTIAL — Institutional Distribution Only**
> These documents are intended solely for authorized institutional counterparties, legal counsel, and programme principals.

## Document Standards

- HTML documents use the standard SSS design system: gold (`#B8860B`/`#C9A84C`) + navy (`#0A1628`) + cream palette
- All market price data presented in these documents that is future-dated relative to the document date must be labeled as scenario/projected
- The `pdf/` subdirectory (if used for rendered PDFs) is excluded from version control via `.gitignore`

## ID Convention

Data room documents: `DOC-DATAROOM-NNN`
