# 04_models

Financial, fiscal, and feasibility models for the AIA-SMCC programme.

All models must carry a scenario/projected disclaimer when market data (gold, silver, commodity prices) is used. Models are for institutional analysis only.

## Intended artifacts

- Financial feasibility models (SSTLC, Dubai Hub, BIBC)
- DASP v2.0 settlement flow models
- DFC/OPIC viability analysis
- Tax and fiscal structure models
- Sensitivity analysis and scenario tables

## Required ID conventions

- Model IDs: `DOC-MODEL-NNN`
- All market data: labeled with date and "scenario/projected" qualifier
