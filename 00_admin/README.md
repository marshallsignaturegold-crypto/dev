# 00_admin

Administrative meta-files for the `marshallsignaturegold-crypto/dev` repository.

This directory contains programme status tracking, governance controls, and operational metadata that do not belong in published deliverables.

## Intended artifacts

- `STATUS.md` — Rolling programme status, critical path items, completed session work
- `CHANGELOG.md` — Versioned change log for the repository
- Operational notes and session records

## Required ID conventions

- Document IDs: `DOC-ADMIN-NNN`
- Governance records: `GOV-ADR-NNNN`
