# 00_admin — Administration & Governance

## Purpose

This directory contains programme-level administrative documents, status trackers, and governance records for the SignatureSovereign SafeTrade Program.

## Intended Artifacts

| File | Description | ID Convention |
|------|-------------|---------------|
| `STATUS.md` | Live programme status tracker | — |
| `DECISIONS.md` | Programme-level decision log | `DOC-ADMIN-NNN` |
| `CONTACTS.md` | Key counterparty contact register | `DOC-ADMIN-NNN` |

## ID Convention

Administrative documents use the prefix: `DOC-ADMIN-NNN`

Example: `DOC-ADMIN-001` — Programme Charter
