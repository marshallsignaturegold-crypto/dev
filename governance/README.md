# governance — Architecture Decision Records

## Purpose

This directory contains Architecture Decision Records (ADRs) documenting significant decisions made about the structure, technology, and conventions of the SignatureSovereign SafeTrade Program repositories.

## Contents

| File | ADR | Decision |
|------|-----|----------|
| `2026-03-27_adr-0001-repository-restructure.md` | ADR-0001 | Adopt canonical `00_admin/` through `08_data_room/` structure |

## ID Convention

ADRs use the prefix: `ADR-NNN`

File naming: `YYYY-MM-DD_adr-NNNN-short-description.md`

## ADR Status Values

- **Proposed** — Under consideration
- **Accepted** — Decision made and implemented
- **Deprecated** — No longer applies
- **Superseded** — Replaced by a newer ADR
