# governance

Architecture Decision Records (ADRs) and change tracking for the repository.

ADRs document significant structural, technical, and operational decisions. This repository uses `GOV-ADR-NNNN` numbering starting at 0002 (ADR-0001 belongs to the companion `sigysovops/IndiSovereign-Operations-S1` repository).

## Intended artifacts

- `YYYY-MM-DD_adr-NNNN-*.md` — Architecture Decision Records
- `CHANGELOG.md` — Cumulative repository change log

## Required ID conventions

- ADR IDs: `GOV-ADR-NNNN`
- Version: `vMAJOR.MINOR.PATCH`
