# 06_outreach — Stakeholder Mapping & Correspondence

## Purpose

This directory contains stakeholder mapping documents, correspondence pipelines, and engagement tracking for the SignatureSovereign SafeTrade Program's government and institutional outreach efforts.

## Intended Artifacts

| File | Description | ID Convention |
|------|-------------|---------------|
| `stakeholder-map.md` | Government and institutional counterparty map | `OC-NNN` |
| `engagement-log.md` | Correspondence and meeting log | `OC-NNN` |
| `dfc-engagement.md` | DFC relationship and application tracking | `OC-NNN` |
| `miga-engagement.md` | MIGA / World Bank engagement | `OC-NNN` |
