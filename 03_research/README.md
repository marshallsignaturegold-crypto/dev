# 03_research

Legal, market, and standards research with sourced evidence tables.

Research files feed the evidence register and support factual claims in deliverables. All claims require a minimum of 3 sources unless documented exception exists.

## Intended artifacts

- Legal jurisdiction analysis (Delaware, UAE, India, Somaliland)
- Market standards research (LBMA, OECD, FATF, BIS)
- Regulatory framework summaries
- Source citation tables (`SRC-NNNN` format)
- Competitor and precedent analysis

## Required ID conventions

- Source IDs: `SRC-NNNN`
- Evidence IDs: `EV-NNNN`
