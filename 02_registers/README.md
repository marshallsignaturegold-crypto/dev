# 02_registers

CSV and structured control-plane registers for programme tracking.

Registers are the single source of truth for enumerable programme data — stakeholders, documents, evidence, variables, and decisions.

## Intended artifacts

- `LR-*.csv` — Legal/regulatory registers
- `OC-*.csv` — Organizational chart registers
- `KPI-*.csv` — Key performance indicators
- `CL-*.csv` — Compliance and legal registers
- `CM-*.csv` — Capital markets registers
- `FM-*.csv` — Financial model registers
- `SH-*.csv` — Stakeholder registers
- `DEC-*.csv` — Decision registers
- `RR-*.csv` — Risk registers

## Required ID conventions

- Register rows: `EV-NNNN`, `VAR-NNNN`, `SRC-NNNN`
