# 02_registers — Control-Plane Data Registers

## Purpose

This directory contains structured control-plane data registers for the SignatureSovereign SafeTrade Program, including legal entity registers, regulatory filings, counterparty registers, and compliance tracking.

## Intended Artifacts

| File | Description | ID Convention |
|------|-------------|---------------|
| `legal-entity-register.md` | All legal entities and filing status | `LR-NNN` |
| `regulatory-register.md` | Regulatory applications and licenses | `LR-NNN` |
| `counterparty-register.md` | MOU/partnership tracking | `OC-NNN` |

## ID Conventions

| Prefix | Domain |
|--------|--------|
| `LR-NNN` | Legal & regulatory registers |
| `OC-NNN` | Outreach & correspondence registers |

Examples:
- `LR-001` — Signature Sovereign Solutions LLC (Delaware)
- `LR-002` — SSTLC (Somaliland Trade & Logistics Co.)
- `OC-001` — Bank of Somaliland preliminary engagement
