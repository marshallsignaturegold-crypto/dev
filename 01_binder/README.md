# 01_binder

Final documents and templates in publishing order for institutional distribution.

This directory holds investor-ready, government-ready, and partner-ready deliverables that have passed review and are cleared for distribution.

## Intended artifacts

- Executive summary documents
- Binding-ready PDF/HTML deliverables
- Cover letters and transmittal memos
- Term sheets and MOU templates
- Presentation decks

## Required ID conventions

- Document IDs: `DOC-BINDER-NNN`
- Version tags: `vMAJOR.MINOR`
