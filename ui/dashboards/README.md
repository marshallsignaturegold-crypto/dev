# ui/dashboards

React TSX compliance and operations dashboards for the AIA-SMCC programme.

All dashboards display Q1 2026 programme data. Market data displayed in dashboards must be understood as scenario projections for modeling purposes.

## Dashboard Inventory

| File | Purpose |
|------|---------|
| `sss-kyc-workflow.tsx` | KYC/AML onboarding workflow and compliance tracking |
| `sss-entity-structure-manager.tsx` | Entity structure, ownership chain, and filing status |
| `sss-treasury-management.tsx` | Cash & liquidity management, bank relationships |
| `sss-political-risk-insurance.tsx` | DFC/OPIC PRI application pipeline and coverage tracker |
| `sss-sanctions-screening.tsx` | OFAC/EU/UN sanctions screening and watchlist management |
| `sss-submodule-matrix.tsx` | Sub-module architecture and integration status matrix |
