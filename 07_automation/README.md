# 07_automation

Generators, validators, CI scripts, and automation tooling for the programme.

## Intended artifacts

- Document generators (Python/Node)
- Register validators and schema checkers
- CI/CD workflow scripts
- Data pipeline scripts
- Report rendering scripts

## Required ID conventions

- Script IDs: `DOC-AUTO-NNN`
- No external secrets or credentials may be embedded; use `secrets.GITHUB_TOKEN` only
