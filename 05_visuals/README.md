# 05_visuals — Diagrams & Presentations

## Purpose

This directory contains visual assets, architecture diagrams, corridor maps, and presentation materials for the SignatureSovereign SafeTrade Program.

## Intended Artifacts

| File | Description |
|------|-------------|
| Architecture diagrams | Entity structure, DASP v2.0 flow, corridor map |
| Presentation decks | Institutional pitch deck (PDF/PPTX) |
| Branding assets | Logos, color palette, typography reference |

## Design System Reference

| Token | Value |
|-------|-------|
| Primary gold | `#B8860B` / `#C9A84C` |
| Navy background | `#0A1628` |
| Cream text | `#F5F0E8` |
| Tailwind accent | `amber-400` / `amber-500` |
| Tailwind dark | `slate-900` |

The visual language uses a **gold + navy + cream** institutional palette consistent across all HTML documents and TSX dashboards.
